<task type="auto">
  <name>Task 3: Implement settings form logic</name>
  <files>
    src/slicehash/static/settings.js
  </files>
  <action>
Create settings.js with form handling:

**On page load:**
1. Fetch current user data from GET /api/users/me
2. Populate form fields with current address and tag values
3. Show loading state while fetching

**Form submission:**
1. Prevent default form submit
2. Get address and tag values from inputs
3. Client-side validation:
   - Bitcoin address matches regex: ^(bc1[a-z0-9]{39,87}|[13][a-km-zA-HJ-NP-Z1-9]{25,34})$
   - Tag max 50 characters
   - Show inline error if validation fails
4. Send PATCH /api/users/me with {address, tag}
5. Handle response:
   - Success (200): Show success message, update form with returned values
   - Validation error (400): Show error message with details
   - Server error (500): Show generic error message

**Error display:**
1. Hide previous messages before showing new ones
2. Display error messages in red error container
3. Display success messages in green success container
4. Auto-hide messages after 5 seconds

**Edge cases:**
- Handle empty form (both fields optional)
- Handle partial updates (only address or only tag)
- Disable submit button during API call
- Re-enable button after response

Use async/await, vanilla JS, no libraries, ~80 lines total.
