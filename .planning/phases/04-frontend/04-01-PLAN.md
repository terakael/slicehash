  <name>Task 3: Implement infinite scroll and data fetching</name>
  <files>
    src/slicehash/static/dashboard.js

  <action>
Create dashboard.js with vanilla JavaScript:

**On page load:**
1. Fetch user data from GET /api/users/me
2. Update header stats: shares_remaining, network difficulty (placeholder: "Calculating..." until /api/traffic/status is called)
3. Initial share fetch: GET /api/users/me/shares?limit=50&offset=0
4. Render shares in table body

**Infinite scroll:**
1. Add scroll event listener to window
2. Check if scrolled near bottom (within 200px)
3. If has_more=true and not currently loading, fetch next page with offset
4. Append new shares to table
5. Show loading indicator during fetch

**Share rendering:**
- Format timestamp as ISO string or "X minutes ago" relative time
- Display log10(share_difficulty) rounded to 2 decimals
- Show billable as green "YES" badge or gray "NO" badge
- Display shares_consumed number

**Error handling:**
- Log fetch errors to console
- Show user-friendly error message ("Failed to load shares") in UI
- Don't crash on API errors

Use async/await, no external libraries, keep under 100 lines.
  </action>
