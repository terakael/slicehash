Create priority.py module with traffic level enum and calculation functions:

**1. TrafficLevel (Enum):**
```python
from enum import Enum

class TrafficLevel(str, Enum):
    GREEN = "green"   # < 10 active users
    ORANGE = "orange"  # 10-25 active users
    RED = "red"        # > 25 active users
```

**2. calculate_traffic_level(active_user_count: int) -> TrafficLevel:**
- Return GREEN if active_user_count < 10
- Return ORANGE if 10 <= active_user_count <= 25
- Return RED if active_user_count > 25
- Simple threshold comparison

**3. calculate_shares_consumed(priority_multiplier: int, traffic_level: TrafficLevel) -> int:**
- Validate priority_multiplier is 1-5 (raise ValueError if not)
- If traffic_level is GREEN: always return 1 (no priority during low traffic)
- If traffic_level is ORANGE or RED: return priority_multiplier
- This implements PRIO-04: green traffic always consumes 1 share regardless of multiplier

Include comprehensive docstrings explaining the fairness rationale:
- Green traffic: everyone equal (1 share per share)
- Orange/red traffic: priority kicks in (1-5 shares per share)

Add type hints for all parameters and returns.
