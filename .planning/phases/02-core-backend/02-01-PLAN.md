Create quota.py module with three async functions:

**1. classify_share_billable(share_difficulty: float, threshold: float) -> bool:**
- Returns True if share_difficulty >= threshold
- Simple comparison function for billable classification

**2. calculate_shares_remaining(db: aiosqlite.Connection, user_id: int) -> int:**
- Query: SUM(transactions.amount WHERE user_id=X) - SUM(share_events.shares_consumed WHERE user_id=X AND billable=1)
- Handle case where user has no transactions (return 0)
- Handle case where user has no billable shares (return full transaction sum)
- Return integer result (shares remaining)

**3. get_active_users(db: aiosqlite.Connection) -> list[int]:**
- Return list of user_ids where shares_remaining > 0
- Use calculate_shares_remaining for each user
- Efficient: query all users once, then calculate for each

Include comprehensive docstrings with parameters, returns, and examples.
