<task type="auto">
  <name>Task 2: Implement four REST API endpoints</name>
  <files>src/slicehash/app.py</files>
  <action>
Add four route handlers to app.py (inside create_app function, after existing routes):

**1. GET /api/users/me** - Return current user data:
- Query users table for user_id=1 (POC hardcoded)
- Return 404 if user not found
- Call calculate_shares_remaining(db, user_id) from quota module
- Call get_active_users(db) to get active count, then calculate_traffic_level(count) from priority module
- Return UserResponse.model_dump() with 200
- Catch exceptions, log, return 500 with generic error
- Follow 03-RESEARCH.md Pattern 3 (Reusing business logic)

**2. PATCH /api/users/me** - Update user address/tag:
- Parse JSON body with await request.get_json()
- Validate with UserUpdateRequest(**data)
- Catch ValidationError specifically, return 400 with error details
- Build dynamic UPDATE query (only include fields that are not None)
- Return 400 if no fields to update
- Execute UPDATE, commit, then fetch updated user (reuse GET logic)
- Return updated UserResponse.model_dump() with 200
- Follow 03-RESEARCH.md Pattern 1 (Pydantic validation in routes)

**3. GET /api/users/me/shares** - Return paginated share history:
- Parse query params: limit (default 50), offset (default 0)
- Clamp limit to 1-100 range, offset to >= 0
- Return 400 if ValueError on int parsing
- Query COUNT(*) from share_events WHERE user_id=1
- Query share_events with ORDER BY submitted_at DESC LIMIT ? OFFSET ?
- Return dict with shares array, total, limit, offset, has_more flag
- Follow 03-RESEARCH.md Pattern 2 (Offset pagination)

**4. GET /api/traffic/status** - Return traffic level:
- Call get_active_users(db) from quota module
- Call calculate_traffic_level(active_count) from priority module
- Return dict with traffic_level (enum .value) and active_user_count
- Follow 03-RESEARCH.md Pattern 3 (Reusing business logic)

All routes:
- Use async with DatabaseManager(app.config["SLICEHASH_CONFIG"].database_path) as db
- Import needed functions: from .quota import calculate_shares_remaining, get_active_users
- Import needed enums: from .priority import calculate_traffic_level, TrafficLevel
- Consistent error handling: ValidationError -> 400, generic Exception -> 500
- All database operations must use await (aiosqlite pattern)

POC note: All endpoints default to user_id=1 (no auth system yet).
