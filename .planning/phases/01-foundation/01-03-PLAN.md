  <action>
Create scripts/add_transaction.py as async CLI tool:

Features:
1. **Command-line arguments:**
   - --address: Bitcoin address (required)
   - --amount: Number of shares to credit (required, integer)
   - --tag: Optional custom label
   - --config: Path to config.yaml (default: "config.yaml")

2. **Workflow:**
   - Load configuration via load_config()
   - Initialize database if not exists via init_database()
   - Get or create user with address/tag via get_or_create_user()
   - Add transaction via add_transaction()
   - Print confirmation with user_id and transaction_id
   - Display current shares_remaining calculation

3. **Shares remaining calculation:**
   - Query SUM(amount) from transactions for user
   - Query SUM(shares_consumed) from share_events WHERE billable=1 for user
   - Display: shares_remaining = transactions_sum - billable_sum

Use argparse for CLI parsing. Use asyncio.run() for async main. Include error handling with clear messages.

Example usage:
```bash
python scripts/add_transaction.py --address bc1q... --amount 1000 --tag "TestUser"
```
